# ToolBox — تطبيق أدوات أندرويد + نسخة ويندوز للنقل

مشروع واحد فيه:
- **`app/`** تطبيق أندرويد (Kotlin + Compose): استخراج APK/XAPK (+OBB اختياري) وتثبيتها، منظف مع الأحجام الحقيقية، معلومات الجهاز، مدير ملفات (zip/7z/rar/tar)، مدير تحميل متعدد الأجزاء مع استئناف، مشغل فيديو/صوت (libVLC)، معرض وعارض صور، HTML/PDF/نصوص، مفكرة بوسائط، محرر صور بسيط، ونقل سريع للكمبيوتر.
- **`desktop/`** برنامج ويندوز: اتصال تلقائي بالجوال، إرسال (سحب وإفلات)، تصفح ملفات الجوال، تنزيل التطبيقات، استقبال الصور تلقائياً، مزامنة الحافظة، مفكرة، وصفحة QR ليرفع الجوال ملفاته للكمبيوتر بدون تطبيق.

## البناء (بدون Android Studio)
1. أنشئ مستودعاً على GitHub وارفع محتوى هذا المجلد كما هو (مع مجلد `.github`).
2. افتح تبويب **Actions** ← **Build ToolBox** ← انتظر انتهاء البناء.
3. من صفحة التشغيل حمّل من **Artifacts**:
   - `ToolBox-Android-APK` (ثبّت `app-universal-release.apk`، أو `arm64-v8a` لمعظم الأجهزة الحديثة)
   - `ToolBox-PC-portable` (مجلد، شغّل `ToolBox.exe`) أو `ToolBox-PC-installer` (MSI)
4. إن ظهر خطأ بناء: انسخ نص الخطأ من Actions وأرسله لـ Claude.

> البناء لم يُجرَّب على Gradle/SDK لأن بيئة الإنشاء بلا SDK ولا إنترنت، فقد تظهر أخطاء تجميع بسيطة في أول تشغيل.

## الاستخدام السريع
- أندرويد: الإعدادات ← امنح «الوصول لكل الملفات» و«الوصول للاستخدام» (للأحجام الحقيقية) و«تثبيت التطبيقات».
- Android/data وobb وتنظيف كاش كل التطبيقات: ثبّت وشغّل **Shizuku** ثم امنح ToolBox صلاحيته.
- النقل: في الجوال **النقل ← تشغيل** (يظهر PIN وQR). في ويندوز افتح ToolBox PC ← اتصال ← اختر الجوال واكتب الـ PIN. نفس الواي فاي أو نقطة اتصال الجوال. أسرع طريقة، والبلوتوث احتياط للملفات الصغيرة.
- أول تشغيل على ويندوز: اسمح للبرنامج في جدار الحماية.

## حدود معروفة
- نقل بلوتوث/واي فاي دايركت بروتوكولياً غير مبني؛ البلوتوث عبر أداة ويندوز `fsquirt` ومشاركة أندرويد.
- قراءة الحافظة في أندرويد 10+ فقط والتطبيق ظاهر.
- اعتراض الروابط من المتصفحات عبر المشاركة/الفتح؛ لا يوجد مستشعر فيديو (m3u8) مثل ADM.
- التطبيق مناسب للتثبيت المباشر وليس Google Play (صلاحيات الملفات والتطبيقات).
